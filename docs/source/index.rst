Spatialsnake 空间转录组实战教程
========================================

本教程基于 ``spatialdata-spatialsnake`` 项目，面向湿实验生物学家与生信分析员设计。
你可以从零开始，按步骤复制粘贴命令，完成从数据读取到下游分析的完整流程。

.. note::

   教程默认你已具备 Linux 命令行基础。
   所有示例命令均可按需替换路径与样本名后直接运行。
